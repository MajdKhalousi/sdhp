# Decision 004 — Core Principles

**Status:** Approved
**Last updated:** Phase 0B

## Purpose

Establishes the seven principles that govern product and engineering decisions across Elaji Health.

## Decision

1. **Daily Clinic First**
2. **Patient-Centered Data**
3. **Permission by Design**
4. **Auditability**
5. **Simple Before Powerful**
6. **Modular Architecture**
7. **Business-Ready Product**

Full explanation of each principle, with practical examples: [../Core-Principles.md](../Core-Principles.md).

## Why This Matters

These principles exist so that ambiguous calls — "should this be configurable or fixed," "does this need an audit log," "is this feature in scope yet" — have a shared standard to resolve against, instead of being decided ad hoc each time.
